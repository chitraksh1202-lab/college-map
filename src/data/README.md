# Data architecture

Three categories, kept separate per `CLAUDE.md`:

- `raw/` — untouched College Scorecard downloads/API responses (Phase 2, not yet built). Gitignored contents; `.gitkeep` only for now.
- `generated/` — clean, normalized output of the import pipeline (`colleges.json`, `search-index.json`, `states.json`). Gitignored; regenerated by `npm run data:import` once that script exists.
- `curated/` — hand-verified editorial data (campus tour points, featured flags, editorial summaries). Committed to git, edited directly as code/JSON.
- `test-colleges.ts` — temporary hand-written dataset (~20 colleges) used only until the real importer exists. Isolated behind `getCollegeBySlug` / `getCollegesByStateCode` so the UI never imports the array directly, and can be swapped for `generated/colleges.json` without touching page/component code.
